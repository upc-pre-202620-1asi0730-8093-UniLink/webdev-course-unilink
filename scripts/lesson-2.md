# Guion · Lección 2: Introducción a HTML (8 min)

**Objetivo:** comprender cómo se organiza un documento HTML y crear desde cero la primera página web, usando las etiquetas `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`, `<h1>` y `<p>`.
**Editor:** CodePen (`https://codepen.io/pen/`), trabajando solo en el panel HTML (`starter-files/lesson-2`). Ejemplo resuelto en `completed-examples/lesson-2`: `index.html` (página construida en la lección) y `ejercicio.html` (solución del ejercicio).
**Recurso visual:** una caja grande (`<html>`) que contiene dos cajas más pequeñas, `<head>` arriba y `<body>` abajo, para explicar la estructura. Una ventana de navegador donde la pestaña representa `<head>` (lo que describe la página) y el área de contenido representa `<body>` (lo que ve el visitante). Usar siempre el mismo color por etiqueta durante todo el video.

**Colores por etiqueta (mantener en todo el video):** `<html>` / `<h1>` = naranja · `<!DOCTYPE html>` / `<head>` = cian · `<title>` = amarillo · `<body>` = morado · `<p>` = cian · apertura / resultado correcto = verde · cierre (la barra `/`) = rosa. En los bloques de código, los nombres de etiqueta van en amarillo y los símbolos `<` `>` en gris.
