¡Hola a todos! Bienvenidos a la primera lección de nuestro curso de Introducción al Desarrollo Web. Hoy vamos a responder una pregunta súper interesante que seguro alguna vez se han hecho: ¿cómo se crea realmente una página web desde cero? No se preocupen si nunca han escrito una sola línea de código en su vida, porque este curso está pensado para empezar totalmente desde cero, paso a paso y con ejemplos súper sencillos. Así que pónganse cómodos.

Piensen en todo lo que hacen en internet todos los días: entran a ver videos en YouTube, revisan sus redes sociales como TikTok o Instagram, o incluso entran a jugar videojuegos web desde su computadora o celular. Todo eso que ven en sus pantallas no aparece por arte de magia; alguien tuvo que diseñarlo y construirlo.

Y lo mejor de todo es lo que ven aquí abajo: hoy en día, para empezar a crear tus propias páginas web, no necesitas una computadora súper potente ni instalar programas pesados. Lo único que vas a necesitar en todo este curso es tu navegador web favorito —puede ser Chrome, Edge, Safari o Firefox— y muchas ganas de experimentar.

Para entender cómo funciona una página por dentro, imaginen que es como construir una casa o como el cuerpo humano. Lo primero que necesitamos es la estructura, los cimientos y los huesos: eso en la web se llama HTML.

El HTML es el lenguaje encargado de poner todo el contenido esencial en la pantalla. Como ven en los íconos, gracias al HTML podemos colocar títulos grandes, párrafos de texto para leer, imágenes de nuestros temas favoritos, videos y hasta botones para interactuar.

Fíjense en la cajita de la derecha: así se ve una página hecha solo con HTML. Tiene el título, el texto, la imagen y el botón, pero todo está apilado uno debajo del otro, en blanco y negro y sin nada de gracia. Tiene el contenido completo, sí, pero cero diseño.

Y aquí es donde entra nuestro segundo protagonista para salvar el día: el CSS. Si el HTML era el esqueleto, el CSS es la ropa, el peinado y toda la personalidad de nuestra página.

Miren la comparación en pantalla. A la izquierda tenemos el antes, solo HTML plano. Al aplicarle CSS, pasamos al después: de repente podemos agregarle colores llamativos a los fondos, cambiar el tipo de letra por fuentes modernas, redondear los bordes de las imágenes y los botones, y ordenar cada elemento exactamente en el lugar donde queremos que esté.

Sin CSS, todas las páginas de internet se verían iguales, aburridas y parecerían documentos antiguos de los años noventa.

Si quieren llevarse una sola idea clave de esta primera clase, que sea esta ecuación que ven en pantalla, nuestra regla de oro: Sitios web = Contenido (HTML) + Estilo (CSS).

Siempre trabajan en equipo: el HTML se encarga de poner las cosas en su sitio y decir qué es cada elemento, mientras que el CSS se encarga de maquillarlas para que se vean increíbles y ordenadas. Cuando dominas estos dos, ya tienes el poder de crear prácticamente cualquier página web que imagines.

Ahora, para que no se quede solo en teoría, queremos que lo vean con sus propios ojos. Aquí abajo en la descripción del video les hemos dejado un enlace directo a CodePen.

¿Qué es CodePen? Es un editor de código en línea gratuito que funciona directo en tu navegador. No tienes que registrarte ni crear una cuenta; simplemente haces clic, se abre una pantalla dividida donde puedes ver el código HTML y CSS por un lado, y el resultado en vivo por el otro. Te reto a que entres, cambies algún texto o color y veas qué pasa.
